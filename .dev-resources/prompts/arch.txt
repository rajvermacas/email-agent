I want to create below system:
Description - When an end user provides some requirement to be fetched from some person, the system should be able to mail the person about requested information, clarifies his doubt in case of some questions, escalate if the required document is not recieved withtin a certain threshold time and validates the requested document received. 

Inputs to the system:
1. The end user has 4 text files
  a. 1st text file - instructions
    example - send mail to raj@gmail.com asking a excel sheet containing 10 rows of food recipes
  b. 2nd text file - faq
    example - frequently asked questions regarding the instructions
  c. escalation - in case the requested piece of information is blocked
    example - if raj@gmail.com is not available or out of office or doesn't reply in 48 hours then reach out to vishal@gmail.com.
    example - If the requested user has clarifying questions about the requirement document and if that information is not present in the input FAQ document then first mail me mrinal@gmail.com, get the answers from me. Share it with raj@gmail.com and wait for his reply.    
  d. validation - what are the steps to validate if the requested information is correct.
    example - the reply should have an attachment with an excel file containing 10 rows of food recipes

Actual components of the system:
1. Supervisor agent - 
this agent will have LLM support

Planning:
reads all the 4 files instructions, faq, escalation, validation and creates a plan and persists the plan on disk, It should even show the plan to the end user before implementing it by rearticulating the user's requirement is its own words so that the end user is confident that the Supervisor Agent has correctly understood the requirement. It checks a2a registry server to know what are all the agents available to perform the task. In the plan it also mentions the execution order of the agents to be performed.



2. Mail agent - 
this agent will have LLM support

For now there will be a single specialised agent like mail agent, but in future there will be other agents also like teams agent, sharepoint agent and so on.

3. Validation agent - 
this agent will have LLM support

Calling validation agent is mandatory which validates the correctness of the requested information.
Validation agent should also have a tool that can run and execute python programs. 
Why? - lets say a requested information has a lot many rows then validation agent can write a python program that analyses and provides the summary to validation agent to vaildate the findings.
